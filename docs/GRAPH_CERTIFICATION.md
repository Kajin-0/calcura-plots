# Graph correctness and performance certification

This renderer is not a grading or symbolic-proof authority. It accepts the
validated graph grammar and preserves caller-provided domain/endpoints/holes.
Inferred sampling boundaries partition provable denominator zeros and periodic
poles; they do not invent semantic hole markers.
Flat probe agreement cannot authorize a chord when a divisor interval still
contains zero or is unresolved. This also protects unpartitioned cubic and
nonlinear trigonometric poles; structural root enumeration is not the sole
continuity authority. Positive-base variable powers have conservative bounds.

## Geometry contract

The sampler clips resolved segments, never independent values. Conservative
real interval enclosures prevent an offscreen probe grid from discarding a
narrow visible crossing or valley. Unknown enclosures mean refine, not assume
offscreen. Periodic argument spans guard against aliasing equal probe values.
Finite/nonfinite boundaries refine beyond one horizontal pixel when their
vertical extent is still visible. Explicit/inferred exclusions split paths even
if no uniform grid hits the excluded coordinate.

Resolved chords target 0.5 pixel vertical residual. Sub-half-pixel monotone
intervals may retain tall finite crossings only when their enclosure agrees
with observed values. Output coordinates are rounded to 0.01 pixel, well below
the error budget. Refinement is bounded by depth 40 and 32,768 evaluations per
function/redraw; recursive siblings and later coarse intervals retain budget.
Pathological unresolved intervals fail closed as gaps, not asymptote bridges.
This is a screen-resolution contract, not a claim to resolve infinitely many
oscillations near the origin of `sin(1/x)` or arbitrary black-box functions.

The fast evaluator must agree with mathjs on the validated AST. Functions with
different mathjs rounding or near-zero conventions use the trusted compiler.
A nonfinite fast result also falls back to the lazily compiled trusted AST,
since complex intermediate values can have a real final result.

## Reproducible gates

`npm run test:unit` includes parser, numeric differential, interval-enclosure,
pole partition, and dense pixel-space fidelity tests. Geometry is tested on
desktop/mobile and zoomed viewports, with independent dense reference samples
and targeted off-grid narrow features. It checks actual distance to polyline
segments, not merely that a path exists. Isolated real evaluations without a
continuous real neighborhood are counted separately from drawable components.
Existing browser tests retain geometry extent, domain markers, selection,
resize, pan/zoom, and asymptote assertions.

The host corpus is generated by Calcura's test-only production-path harness:

```sh
# In Calcura:
npm run test:freeplay-graph-corpus -- /tmp/calcura-generated-graphs.json
# In calcura-plots, after npm run build:lib:
npm run test:generated-corpus -- /tmp/calcura-generated-graphs.json
```

Generation guards that reject a problem are reported separately, never counted
as graph passes. Unsupported syntax is likewise separate. The final public API
run fails on compile or missing-visible-geometry errors; an optional historical
checkout argument records retrospective failures without pretending they pass.

`npm run benchmark:graph -- /path/to/checkout` reports compile/evaluation/sampler
timings, bounded evaluations, points, and segment counts. Browser performance
tests report navigation/open latency, pan completion, frame intervals, long
tasks, actual draw duration/count, and SVG path bytes. Browser automation
completion times include input/polling overhead; they are not raw render time.
Timings are lab evidence, not universal Android-device performance claims.

Android shell/API-36 WebView certification remains in the existing CI matrix.
An owner real-device manual checkpoint is required before publishing Calcura.
